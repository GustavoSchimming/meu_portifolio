Portfólio Pessoal - Gustavo Schimming

Este é um projeto de portfólio pessoal desenvolvido para apresentar meus dados de perfil, conhecimentos técnicos, habilidades e projetos na área de Desenvolvimento de Software.

🚀 Sobre o Projeto

O objetivo principal deste projeto é criar uma página web simples, limpa e estruturada para demonstrar os aprendizados em tecnologias fundamentais do desenvolvimento web.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica do conteúdo da página.

CSS3: Estilização, alinhamento e dimensionamento dos elementos.

📌 Funcionalidades

Cabeçalho com Apresentação: Nome e título profissional.

Menu de Navegação: Links diretos para as seções da página.

Seção "Sobre Mim":

Foto de perfil formatada.

Breve descrição sobre minha trajetória e estudos.

Lista de Habilidades: Habilidades técnicas em destaque.

Seção "Meus Projetos": Galeria/lista dos projetos desenvolvidos.

📂 Como Executar o Projeto

Clone este repositório ou faça o download dos arquivos:

git clone https://github.com/seu-usuario/seu-repositorio.git


Abra a pasta do projeto.

Clique duas vezes no arquivo index.html para visualizá-lo em qualquer navegador de sua preferência.
